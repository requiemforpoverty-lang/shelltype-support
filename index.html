01 · Get started

Enable ShellType C+

  1. Open Settings → General → Keyboard → Keyboards.
  2. Tap Add New Keyboard and select ShellType C+.
  3. Open a text field, hold the globe, and choose ShellType C+.

Use the globe on ShellType C+ to switch to another installed keyboard.

02 · Make it yours

Create a keyboard

  1. In ShellType C+, open Layouts → Create keyboard.
  2. Start empty or choose a template. Use Add key, select a key, and assign its action.
  3. Drag into a free space. Resize in whole cells; an occupied drop returns the key to its previous position.
  4. Tap Done, name the keyboard, and save.

Common questions

My custom keyboard is missing in another app.

Save it with Done in ShellType C+. Return to the other app, switch away from ShellType C+ using the globe, then select ShellType C+ again. The named button inside ShellType C+ switches between your saved layouts: its label is the next layout, not the current one. If the layout still does not appear, contact support before deleting or reinstalling the app, which can remove saved layouts.

Why do arrows type symbols such as [A or [B?

Terminal arrow modes send escape sequences. A regular text field can display parts of those sequences instead of moving the cursor. In Layouts, choose the Text cursor arrow mode for ordinary text editing. Normal and Application modes are for terminal software that interprets the corresponding sequences. Compatibility depends on the receiving app and its configuration.

Is ShellType C+ an SSH client?

No. ShellType C+ provides a keyboard for another app; it does not connect to servers. Terminal shortcuts require a receiving terminal app that supports the control characters or escape sequences being sent. ShellType C+ does not guarantee that every shortcut works in every app.

Why does iOS sometimes show the Apple keyboard?

Secure password fields and some other input fields use the system keyboard. Apps can also disallow third-party keyboards. ShellType C+ cannot override these restrictions.

What does Allow Full Access mean?

iOS shows a general warning for this permission. ShellType C+ does not send your typing to a server. It uses local shared storage for the app and keyboard; Full Access also enables the legacy-layout transfer path. To import layouts from an older version, follow the instructions under Import previous layouts in the app. You can turn Full Access off again in Settings → General → Keyboard → Keyboards → ShellType C+.

Where do I change the order, color, or brightness?

On Home, hold and drag layout names to change their order; the first opens by default. Pick a layout’s accent in Layouts. Adjust backlight brightness in Try it. The System accent keeps keys neutral without colored backlighting.

How do I remove a keyboard?

In Layouts, open its three-dot menu and choose Delete. Deletion is immediate. A built-in template can be used to create a new keyboard later; it does not recover edits made to a deleted custom layout.

How do I report a crash or a problem?

Email your iPhone or iPad model, iOS/iPadOS version, ShellType C+ version and build number, the app where the issue occurred, and the steps to reproduce it. For a TestFlight build, find the version in TestFlight. A screenshot or short recording can help. Remove private messages, passwords, server credentials, and other sensitive information before sending.
